# Skip Link Variations

Explore advanced skip link implementations including multiple skip links, custom visual designs, and mobile-optimized solutions.

## Multiple Skip Links

Provide multiple skip links for different content sections to give users more navigation options.

### Implementation

```html
<body>
  <div class="skip-links">
    <a href="#main-content" class="skip-link">
      Skip to main content
    </a>
    <a href="#navigation" class="skip-link">
      Skip to navigation
    </a>
    <a href="#search" class="skip-link">
      Skip to search
    </a>
  </div>
  
  <header>
    <nav id="navigation">
      <!-- Navigation content -->
    </nav>
  </header>
  
  <main id="main-content">
    <!-- Main content -->
  </main>
  
  <aside id="search">
    <!-- Search content -->
  </aside>
</body>
```

### CSS for Multiple Skip Links

```css
.skip-links {
  position: absolute;
  top: -100px;
  left: 0;
  z-index: 100;
}

.skip-link {
  display: block;
  background: #000;
  color: #fff;
  padding: 8px 16px;
  text-decoration: none;
  font-size: 1rem;
  margin-bottom: 4px;
}

.skip-link:focus {
  position: relative;
  top: 0;
}
```

### When to Use Multiple Skip Links

- **Complex Sites**: Sites with multiple major content sections
- **E-commerce**: Products, reviews, related items
- **Documentation**: Content, navigation, search
- **Dashboards**: Main content, sidebar, tools

```javascript
// Add keyboard shortcut

      skipLink.click();
    }
  }
});
```

## Best Practices for Variations

### 1. Maintain Accessibility

Regardless of visual design, ensure skip links remain accessible:

- Always visible on focus
- Sufficient color contrast (4.5:1 minimum)
- Large enough touch targets (44x44px minimum)
- Clear, descriptive text

### 2. Test Across Devices

Test skip links on:

- Desktop browsers
- Mobile browsers
- Tablet devices
- Different screen sizes
- Different input methods (keyboard, touch, mouse)

### 3. Consider User Preferences

- Respect user's preferred color scheme
- Honor reduced motion preferences
- Support high contrast mode
- Work with custom stylesheets
