Select dropdowns allow users to choose from a list of options. They are ideal for choice selection when there are many options.

## Overview

Accessible select dropdowns have clear labels, proper semantic markup, and work seamlessly with assistive technologies.

## Basic Select

Select dropdowns allow users to choose from a list of options.

```html
<div class="form-group">
  <label for="country">Country</label>
  <select 
    id="country" 
    name="country"
    required
    aria-required="true"
  >
    <option value="">Select a country</option>
    <option value="us">United States</option>
    <option value="ca">Canada</option>
    <option value="uk">United Kingdom</option>
    <option value="au">Australia</option>
  </select>
</div>
```

### Key Attributes

- `id`: Unique identifier for label association
- `name`: Form submission name
- `required`: Indicates field is required
- `aria-required="true"`: Indicates required state to screen readers

### Best Practices

- Include a default "Select..." option
- Use `required` attribute for mandatory selections
- Provide clear, descriptive option text
- Group related options with `optgroup`

## Select with Optgroups

Use `optgroup` to group related options for better organization.

```html
<div class="form-group">
  <label for="state">State</label>
  <select id="state" name="state">
    <optgroup label="Northeast">
      <option value="ny">New York</option>
      <option value="ma">Massachusetts</option>
    </optgroup>
    <optgroup label="West Coast">
      <option value="ca">California</option>
      <option value="wa">Washington</option>
    </optgroup>
  </select>
</div>
```

### Key Points

- Use `optgroup` to group related options
- Each `optgroup` should have a descriptive label
- Options can be grouped logically (by region, category, etc.)
- Nested `optgroup` elements are not supported

## Multiple Select

Allow users to select multiple options.

```html
<div class="form-group">
  <label for="interests">Interests (select multiple)</label>
  <select 
    id="interests" 
    name="interests"
    multiple
    size="5"
    aria-describedby="interests-help"
  >
    <option value="tech">Technology</option>
    <option value="design">Design</option>
    <option value="marketing">Marketing</option>
    <option value="sales">Sales</option>
    <option value="support">Support</option>
  </select>
  <span id="interests-help" class="help-text">
    Hold Ctrl/Cmd to select multiple options
  </span>
</div>
```

### Key Attributes

- `multiple`: Allows multiple selections
- `size`: Number of visible options (recommended for multiple selects)

### Best Practices

- Use `size` attribute to show multiple options
- Provide help text explaining how to select multiple options
- Consider using checkboxes instead for small lists of options

## Select with Default Selection

Pre-select an option using the `selected` attribute.

```html
<div class="form-group">
  <label for="country">Country</label>
  <select id="country" name="country">
    <option value="">Select a country</option>
    <option value="us">United States</option>
    <option value="ca">Canada</option>
    <option value="uk" selected>United Kingdom</option>
    <option value="au">Australia</option>
  </select>
</div>
```

### Best Practices

- Use `selected` attribute for default selection
- Don't use `selected` on multiple options
- Ensure default option makes sense for your use case

## Common Mistakes

### 1. Missing Default Option

```html
<!-- Bad: No default option -->
<select id="country" name="country">
  <option value="us">United States</option>
  <option value="ca">Canada</option>
</select>

<!-- Good: With default option -->
<select id="country" name="country">
  <option value="">Select a country</option>
  <option value="us">United States</option>
  <option value="ca">Canada</option>
</select>
```

### 2. Not Grouping Related Options

```html
<!-- Bad: Not grouping -->
<select id="state" name="state">
  <option value="ny">New York</option>
  <option value="ma">Massachusetts</option>
  <option value="ca">California</option>
  <option value="wa">Washington</option>
</select>

<!-- Good: Grouping with optgroup -->
<select id="state" name="state">
  <optgroup label="Northeast">
    <option value="ny">New York</option>
    <option value="ma">Massachusetts</option>
  </optgroup>
  <optgroup label="West Coast">
    <option value="ca">California</option>
    <option value="wa">Washington</option>
  </optgroup>
</select>
```

### 3. Using Multiple Select Without Size

```html
<!-- Bad: Multiple select without size -->
<select id="interests" name="interests" multiple>
  <option value="tech">Technology</option>
  <option value="design">Design</option>
</select>

<!-- Good: Multiple select with size -->
<select id="interests" name="interests" multiple size="5">
  <option value="tech">Technology</option>
  <option value="design">Design</option>
</select>
```

## Testing Checklist

### Keyboard Navigation
- [ ] Can navigate to select using Tab
- [ ] Can open select dropdown using Alt+Down (Windows) or Option+Down (Mac)
- [ ] Can navigate options using arrow keys
- [ ] Can select option using Enter or Space
- [ ] Focus indicators are visible

### Screen Reader Testing
- [ ] Label is announced
- [ ] Required field is identified
- [ ] Option groups are announced
- [ ] Selected option is announced
- [ ] Number of options is announced

### Visual Testing
- [ ] Label is visually associated with select
- [ ] Required field is clearly marked
- [ ] Focus indicator is visible
- [ ] Selected option is clearly visible
- [ ] Color contrast is sufficient
