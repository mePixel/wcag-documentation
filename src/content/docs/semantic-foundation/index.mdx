# HTML Elements

This section covers semantic HTML elements and their accessibility features. Using the right HTML elements for the right purpose is the foundation of web accessibility.

## Overview

HTML provides built-in accessibility features that work with assistive technologies. Semantic HTML elements convey meaning and structure, making content accessible to all users.

### Why Semantic HTML Matters

- **Screen Reader Users**: Understand content structure and navigate efficiently
- **Keyboard Users**: Navigate and interact with content without a mouse
- **Search Engines**: Better understand and index your content
- **All Users**: Benefit from consistent, predictable behavior

## Best Practices

### 1. Use Semantic HTML

Choose elements based on meaning, not appearance.

```html
<!-- Good: Semantic HTML -->
<button type="button">Submit</button>
<a href="/about">About</a>
<h1>Page Title</h1>

<!-- Bad: Non-semantic HTML -->
<div class="button" onclick="submitForm()">Submit</div>
<div class="link" onclick="navigate('/about')">About</div>
<div class="title">Page Title</div>
```

### 2. Maintain Proper Hierarchy

Use elements in their proper order and nesting.

```html
<!-- Good: Proper hierarchy -->
<h1>Main Title</h1>
<h2>Section Title</h2>
<h3>Subsection Title</h3>

<!-- Bad: Incorrect hierarchy -->
<h1>Main Title</h1>
<h3>Subsection Title</h3>
```

### 3. Provide Complete Information

Ensure all elements have necessary attributes.

```html
<!-- Good: Complete attributes -->
<img src="photo.jpg" alt="Sunset over the ocean">
<label for="email">Email Address</label>
<input type="email" id="email" required>

<!-- Bad: Missing attributes -->
<img src="photo.jpg">
<input type="email" placeholder="Email Address">
```

### 4. Use Landmarks Appropriately

Use landmark elements to define page structure.

```html
<!-- Good: Proper landmarks -->
<header>
  <nav>
    <!-- Navigation -->
  </nav>
</header>

<main>
  <article>
    <!-- Main content -->
  </article>
  
  <aside>
    <!-- Sidebar content -->
  </aside>
</main>

<footer>
  <!-- Footer content -->
</footer>
```

## Common Mistakes

### 1. Using Divs Instead of Semantic Elements

```html
<!-- Bad: Using divs -->
<div class="button" onclick="submitForm()">Submit</div>

<!-- Good: Using button element -->
<button type="button">Submit</button>
```

### 2. Skipping Heading Levels

```html
<!-- Bad: Skipping levels -->
<h1>Title</h1>
<h3>Subtitle</h3>

<!-- Good: Proper hierarchy -->
<h1>Title</h1>
<h2>Subtitle</h2>
```

### 3. Missing Alt Text

```html
<!-- Bad: No alt text -->
<img src="chart.png">

<!-- Good: Descriptive alt text -->
<img src="chart.png" alt="Bar chart showing 50% increase in sales">
```

### 4. Using Placeholder Text as Labels

```html
<!-- Bad: Placeholder as label -->
<input type="email" placeholder="Email Address">

<!-- Good: Proper label -->
<label for="email">Email Address</label>
<input type="email" id="email">
```
