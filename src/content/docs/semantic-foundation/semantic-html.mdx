Semantic HTML uses HTML elements for their intended purpose, providing meaning and structure that assistive technologies can understand. This is the foundation of web accessibility.

## Overview

Semantic HTML elements convey meaning about the type of content they contain, not just how it should look. This meaning helps assistive technologies present content appropriately to users.

### Why Semantic HTML Matters

- **Screen Reader Users**: Navigate by element type (headings, landmarks, lists)
- **Keyboard Users**: Interact with elements using standard keyboard shortcuts
- **Search Engines**: Better understand and index your content
- **All Users**: Benefit from consistent, predictable behavior

## Quick Reference

### Common Semantic Elements

| Element | Purpose | Example |
|----------|---------|---------|
| `<h1>`-`<h6>` | Headings | `<h1>Page Title</h1>` |
| `<p>` | Paragraphs | `<p>Paragraph text</p>` |
| `<ul>`, `<ol>` | Lists | `<ul><li>Item</li></ul>` |
| `<a>` | Links | `<a href="/about">About</a>` |
| `<button>` | Buttons | `<button type="submit">Submit</button>` |
| `<img>` | Images | `<img src="photo.jpg" alt="Description">` |
| `<nav>` | Navigation | `<nav><a href="/">Home</a></nav>` |
| `<main>` | Main content | `<main><h1>Main</h1></main>` |
| `<article>` | Self-contained content | `<article><h2>Article</h2></article>` |
| `<section>` | Grouped content | `<section><h2>Section</h2></section>` |

### Common Mistakes

1. **Using divs instead of semantic elements**
   - Bad: `<div class="button">Submit</div>`
   - Good: `<button type="button">Submit</button>`

2. **Skipping heading levels**
   - Bad: `<h1>Title</h1><h3>Subtitle</h3>`
   - Good: `<h1>Title</h1><h2>Subtitle</h2>`

3. **Using non-descriptive link text**
   - Bad: `<a href="/about">Click here</a>`
   - Good: `<a href="/about">Learn about our company</a>`

4. **Missing alt text**
   - Bad: `<img src="chart.png">`
   - Good: `<img src="chart.png" alt="Bar chart showing sales data">`
