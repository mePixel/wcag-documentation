# Table Elements

Table elements are used to present data in a tabular format. Proper table structure is essential for accessibility.

## Table (table)

The `<table>` element creates a data table.

### Basic Table Structure

```html
<table>
  <caption>Monthly Sales Data</caption>
  <thead>
    <tr>
      <th scope="col">Month</th>
      <th scope="col">Sales</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">January</th>
      <td>$10,000</td>
    </tr>
    <tr>
      <th scope="row">February</th>
      <td>$12,000</td>
    </tr>
  </tbody>
</table>
```

### Table Components

#### Caption

The `<caption>` element provides a title or description for the table.

```html
<table>
  <caption>Monthly Sales Data for 2024</caption>
  <!-- Table content -->
</table>
```

**Why captions matter:**
- Screen readers announce the caption
- Provides context for table content
- Helps users understand table purpose

#### Thead (Table Header)

The `<thead>` element groups the header content in a table.

```html
<table>
  <thead>
    <tr>
      <th scope="col">Product</th>
      <th scope="col">Price</th>
      <th scope="col">Quantity</th>
    </tr>
  </thead>
  <tbody>
    <!-- Table body content -->
  </tbody>
</table>
```

#### Tbody (Table Body)

The `<tbody>` element groups the body content in a table.

```html
<table>
  <thead>
    <!-- Header content -->
  </thead>
  <tbody>
    <tr>
      <td>Product A</td>
      <td>$10.00</td>
      <td>5</td>
    </tr>
    <tr>
      <td>Product B</td>
      <td>$15.00</td>
      <td>3</td>
    </tr>
  </tbody>
</table>
```

#### Tfoot (Table Footer)

The `<tfoot>` element groups the footer content in a table.

```html
<table>
  <thead>
    <!-- Header content -->
  </thead>
  <tbody>
    <!-- Body content -->
  </tbody>
  <tfoot>
    <tr>
      <td colspan="2">Total</td>
      <td>$95.00</td>
    </tr>
  </tfoot>
</table>
```

#### Tr (Table Row)

The `<tr>` element defines a row of cells in a table.

```html
<tr>
  <th scope="row">Product A</th>
  <td>$10.00</td>
  <td>5</td>
</tr>
```

#### Th (Table Header Cell)

The `<th>` element defines a header cell in a table.

```html
<th scope="col">Product</th>
<th scope="row">Product A</th>
```

**Key attribute:**
- `scope`: Specifies whether header is for a column (`col`) or row (`row`)

#### Td (Table Data Cell)

The `<td>` element defines a data cell in a table.

```html
<td>$10.00</td>
<td>5</td>
```

## Scope Attribute

The `scope` attribute is crucial for table accessibility. It specifies which cells the header cell applies to.

### Column Scope

```html
<thead>
  <tr>
    <th scope="col">Product</th>
    <th scope="col">Price</th>
    <th scope="col">Quantity</th>
  </tr>
</thead>
```

Indicates that the header applies to all cells in the column.

### Row Scope

```html
<tbody>
  <tr>
    <th scope="row">Product A</th>
    <td>$10.00</td>
    <td>5</td>
  </tr>
</tbody>
```

Indicates that the header applies to all cells in the row.

### Column Group Scope

```html
<thead>
  <tr>
    <th scope="colgroup">Q1</th>
    <th scope="col">January</th>
    <th scope="col">February</th>
    <th scope="col">March</th>
  </tr>
</thead>
```

Indicates that the header applies to a group of columns.

### Row Group Scope

```html
<tbody>
  <tr>
    <th scope="rowgroup">Electronics</th>
    <td>Laptop</td>
    <td>$1,000</td>
  </tr>
  <tr>
    <td>Phone</td>
    <td>$500</td>
  </tr>
</tbody>
```

Indicates that the header applies to a group of rows.

## Complex Tables

### Multi-Level Headers

For tables with multiple levels of headers, use the `headers` attribute.

```html
<table>
  <caption>Product Sales by Region</caption>
  <thead>
    <tr>
      <th colspan="2" scope="colgroup">North America</th>
      <th colspan="2" scope="colgroup">Europe</th>
    </tr>
    <tr>
      <th scope="col" id="na-us">US</th>
      <th scope="col" id="na-ca">Canada</th>
      <th scope="col" id="eu-uk">UK</th>
      <th scope="col" id="eu-de">Germany</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Product A</th>
      <td headers="na-us">$10,000</td>
      <td headers="na-ca">$5,000</td>
      <td headers="eu-uk">$8,000</td>
      <td headers="eu-de">$7,000</td>
    </tr>
  </tbody>
</table>
```

### Headers Attribute

The `headers` attribute associates a data cell with its corresponding header cells.

```html
<td headers="na-us">$10,000</td>
```

The value is a space-separated list of header cell IDs.

## Best Practices

### 1. Use Tables for Data Only

Tables should only be used for tabular data, not for layout.

```html
<!-- Good: Table for data -->
<table>
  <caption>Monthly Sales</caption>
  <thead>
    <tr>
      <th scope="col">Month</th>
      <th scope="col">Sales</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>January</td>
      <td>$10,000</td>
    </tr>
  </tbody>
</table>

<!-- Bad: Table for layout -->
<table>
  <tr>
    <td>Navigation</td>
    <td>Content</td>
  </tr>
</table>
```

### 2. Always Include a Caption

Provide a caption that describes the table's purpose.

```html
<!-- Good: With caption -->
<table>
  <caption>Monthly Sales Data for 2024</caption>
  <!-- Table content -->
</table>

<!-- Bad: No caption -->
<table>
  <!-- Table content -->
</table>
```

### 3. Use Scope Attribute

Always use the `scope` attribute on header cells.

```html
<!-- Good: With scope -->
<th scope="col">Product</th>
<th scope="row">Product A</th>

<!-- Bad: No scope -->
<th>Product</th>
<th>Product A</th>
```

### 4. Use Proper Table Structure

Use `<thead>`, `<tbody>`, and `<tfoot>` to structure your table.

```html
<!-- Good: Proper structure -->
<table>
  <caption>Monthly Sales</caption>
  <thead>
    <tr>
      <th scope="col">Month</th>
      <th scope="col">Sales</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>January</td>
      <td>$10,000</td>
    </tr>
  </tbody>
</table>

<!-- Bad: Improper structure -->
<table>
  <tr>
    <th>Month</th>
    <th>Sales</th>
  </tr>
  <tr>
    <td>January</td>
    <td>$10,000</td>
  </tr>
</table>
```

### 5. Avoid Empty Cells

Empty cells can confuse screen readers. Use `&nbsp;` or provide content.

```html
<!-- Good: No empty cells -->
<tr>
  <td>Product A</td>
  <td>$10.00</td>
  <td>5</td>
</tr>

<!-- Bad: Empty cell -->
<tr>
  <td>Product A</td>
  <td></td>
  <td>5</td>
</tr>
```

## Common Mistakes

### 1. Using Tables for Layout

```html
<!-- Bad: Table for layout -->
<table>
  <tr>
    <td>Navigation</td>
    <td>Content</td>
  </tr>
</table>

<!-- Good: Using CSS for layout -->
<div class="container">
  <nav>Navigation</nav>
  <main>Content</main>
</div>
```

### 2. Missing Scope Attribute

```html
<!-- Bad: No scope -->
<th>Product</th>

<!-- Good: With scope -->
<th scope="col">Product</th>
```

### 3. Missing Caption

```html
<!-- Bad: No caption -->
<table>
  <!-- Table content -->
</table>

<!-- Good: With caption -->
<table>
  <caption>Monthly Sales Data</caption>
  <!-- Table content -->
</table>
```

### 4. Using Empty Cells

```html
<!-- Bad: Empty cell -->
<tr>
  <td>Product A</td>
  <td></td>
  <td>5</td>
</tr>

<!-- Good: No empty cells -->
<tr>
  <td>Product A</td>
  <td>N/A</td>
  <td>5</td>
</tr>
```
