# WCAG 2.1 AA Success Criteria

This section provides detailed information about all WCAG 2.1 Level AA success criteria. Each criterion includes the requirement, understanding, techniques, and examples.

## Success Criteria by Principle

### Perceivable Criteria

Information and user interface components must be presentable to users in ways they can perceive.

- [Perceivable Criteria](./perceivable-criteria.mdx) - All 13 perceivable success criteria

### Operable Criteria

User interface components and navigation must be operable.

- [Operable Criteria](./operable-criteria.mdx) - All 20 operable success criteria

### Understandable Criteria

Information and the operation of the user interface must be understandable.

- [Understandable Criteria](./understandable-criteria.mdx) - All 10 understandable success criteria

### Robust Criteria

Content must be robust enough that it can be interpreted reliably by a wide variety of user agents.

- [Robust Criteria](./robust-criteria.mdx) - All 4 robust success criteria

## Understanding Success Criteria

Each success criterion includes:

### Requirement
The specific accessibility requirement that must be met.

### Understanding
Detailed explanation of what the criterion means and why it's important.

### Techniques
Specific methods for meeting the criterion, including:
- **Sufficient Techniques**: Methods that alone meet the criterion
- **Advisory Techniques**: Additional methods that enhance accessibility

### Examples
Practical examples of compliant and non-compliant implementations.

### Common Failures
Frequently occurring mistakes that cause the criterion to fail.

## Success Criteria Format

Each criterion is identified by a number in the format `X.Y.Z`:

- **X**: Principle (1 = Perceivable, 2 = Operable, 3 = Understandable, 4 = Robust)
- **Y**: Guideline (e.g., 1.1 = Text Alternatives)
- **Z**: Specific criterion within the guideline

Example: `1.4.3` = Perceivable (1) → Distinguishable (1.4) → Contrast (Minimum) (1.4.3)

## Conformance Levels

Each success criterion has a conformance level:

- **Level A**: Minimum accessibility requirements
- **Level AA**: Addresses the most common accessibility barriers
- **Level AAA**: Highest level of accessibility

This reference focuses on Level AA criteria, which is the most commonly adopted standard.
