# 2.5 Input Modalities

Make it easier for users to operate functionality through various inputs beyond keyboard.

## 2.5.1 Pointer Gestures (Level A)

**Requirement**: All functionality that uses multipoint or path-based gestures for operation can be operated with a single pointer without a path-based gesture, unless a multipoint or path-based gesture is essential.

**Understanding**: Users with motor impairments may not be able to perform complex gestures. Provide simple alternatives.

**Sufficient Techniques**:
- **G215**: Ensuring that touch targets are at least 44 by 44 CSS pixels

**Example**:
```javascript
// Bad: Requires complex gesture
element.addEventListener('touchmove', (e) => {
  // Requires drawing a circle
  if (isCircleGesture(e)) {
    performAction();
  }
});

// Good: Simple tap alternative
element.addEventListener('click', () => {
  performAction();
});

// Or provide both
element.addEventListener('click', () => {
  performAction();
});
element.addEventListener('touchmove', (e) => {
  if (isCircleGesture(e)) {
    performAction();
  }
});
```

## 2.5.2 Pointer Cancellation (Level A)

**Requirement**: For functionality that can be operated using a single pointer, at least one of the following is true:
- No Down-Event: The down-event of the pointer is not used to execute any part of the function
- Abort or Undo: Completion of the function is on the up-event, and a mechanism is available to abort the function before completion or to undo the function after completion
- Up Reversal: The up-event reverses any outcome of the preceding down-event
- Essential: Completing the function on the down-event is essential

**Understanding**: Users with motor impairments may accidentally activate controls. Provide ways to cancel or undo actions.

**Sufficient Techniques**:
- **G213**: Providing a text alternative on the same page as the non-text content

**Example**:
```javascript
// Good: Action completes on up-event, can be cancelled
let isDragging = false;
let startX, startY;

element.addEventListener('mousedown', (e) => {
  isDragging = true;
  startX = e.clientX;
  startY = e.clientY;
});

element.addEventListener('mousemove', (e) => {
  if (!isDragging) return;
  // Preview action
  previewAction(e.clientX - startX, e.clientY - startY);
});

element.addEventListener('mouseup', (e) => {
  if (!isDragging) return;
  isDragging = false;
  // Complete action
  completeAction(e.clientX - startX, e.clientY - startY);
});

// Allow cancellation
document.addEventListener('keydown', (e) => {
  if (e.key === 'Escape') {
    isDragging = false;
    cancelAction();
  }
});
```

## 2.5.3 Label in Name (Level A)

**Requirement**: For user interface components with labels that include text or images of text, the name contains the text that is presented visually.

**Understanding**: The accessible name should match or include the visible label to avoid confusion.

**Sufficient Techniques**:
- **G208**: Ensuring that the accessible name contains the visible label text

**Example**:
```html
<!-- Good: Accessible name matches visible label -->
<button>Submit Form</button>

<!-- Good: Accessible name includes visible label -->
<button aria-label="Submit form to continue">Submit</button>

<!-- Bad: Accessible name doesn't match visible label -->
<button aria-label="Continue to next step">Submit</button>
```

## 2.5.4 Motion Actuation (Level A)

**Requirement**: Functionality that can be operated by device motion or user motion can also be operated by user interface components and responding to the motion can be disabled to prevent accidental actuation, except when:
- Supported Interface: The motion is used to operate functionality through an interface supported by accessibility and the motion is essential for the function and the response to the motion is not used to operate any other functionality
- Essential: The motion is essential for the function and doing so would invalidate the activity

**Understanding**: Motion-based controls can be difficult for users with motor impairments. Provide alternatives.

**Sufficient Techniques**:
- **G217**: Providing a way to turn off character key shortcuts

**Example**:
```javascript
// Good: Provide alternative controls
let motionEnabled = false;

// Toggle switch
document.getElementById('motionToggle').addEventListener('change', (e) => {
  motionEnabled = e.target.checked;
});

// Motion control (only when enabled)
window.addEventListener('devicemotion', (e) => {
  if (!motionEnabled) return;
  // Handle motion
});

// Alternative button control
document.getElementById('actionButton').addEventListener('click', () => {
  performAction();
});
```
