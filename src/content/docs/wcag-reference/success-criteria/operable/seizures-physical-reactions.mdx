# 2.3 Seizures and Physical Reactions

Web pages must not contain anything that flashes more than three times in any one second period, or the flash is below the general flash and red flash thresholds.

## 2.3.1 Three Flashes or Below Threshold (Level A)

**Requirement**: Web pages do not contain anything that flashes more than three times in any one second period, or the flash is below the general flash and red flash thresholds.

**Understanding**: Flashing content can trigger seizures in people with photosensitive epilepsy. Limit flashing to safe levels.

**Sufficient Techniques**:
- **G19**: Ensuring that no component of the content flashes more than three times in any 1-second period

**Example**:
```css
/* Bad: Rapid flashing */
@keyframes flash {
  0%, 100% { opacity: 1; }
  50% { opacity: 0; }
}

.flashing {
  animation: flash 0.2s infinite; /* 5 flashes per second - too fast! */
}

/* Good: Slower animation */
@keyframes pulse {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.7; }
}

.pulsing {
  animation: pulse 2s infinite; /* 0.5 flashes per second - safe */
}
```
