# 2.1 Keyboard Accessible

All functionality must be operable through a keyboard interface without requiring specific timings for individual keystrokes, except where the underlying function requires input that depends on the path of the user's movement and not just the endpoints.

## 2.1.1 Keyboard (Level A)

**Requirement**: All functionality of the content is operable through a keyboard interface without requiring specific timings for individual keystrokes, except where the underlying function requires input that depends on the path of the user's movement and not just the endpoints.

**Understanding**: Users who cannot use a mouse rely on keyboard navigation. All interactive elements must be accessible via keyboard.

**Sufficient Techniques**:
- **G202**: Ensuring keyboard control for all functionality
- **G205**: Providing a mechanism to allow the user to display and, from the display, access the description of a non-text object
- **G206**: Using a public standard API with support for accessibility to implement functionality

**Example**:
```html
<!-- All interactive elements must be keyboard accessible -->
<button type="button">Submit</button>
<a href="/about">About</a>
<input type="text" name="email">
<select name="country">
  <option value="us">United States</option>
</select>

<!-- Custom components must be keyboard accessible -->
<div role="button" tabindex="0" onclick="handleClick()" onkeydown="handleKeydown(event)">
  Custom Button
</div>
```

## 2.1.2 No Keyboard Trap (Level A)

**Requirement**: If keyboard focus can be moved to a component of the page using a keyboard interface, then focus can be moved away from that component using only a keyboard interface, and, if it requires more than unmodified arrow or tab keys or other standard exit methods, the user is advised of the method for moving focus away.

**Understanding**: Users must be able to navigate away from any component using only the keyboard. Focus should never be trapped.

**Sufficient Techniques**:
- **G21**: Ensuring that users are not trapped in content
- **SCR35**: Making actions keyboard accessible by using the onclick event of anchors and buttons

**Example**:
```javascript
// Bad: Focus is trapped in modal
function openModal() {
  modal.style.display = 'block';
  modal.focus();
  // No way to escape!
}

// Good: Provide escape mechanism
function openModal() {
  modal.style.display = 'block';
  modal.focus();
  
  // Allow escape key to close
  modal.addEventListener('keydown', (e) => {
    if (e.key === 'Escape') {
      closeModal();
    }
  });
}

function closeModal() {
  modal.style.display = 'none';
  // Return focus to trigger element
  triggerElement.focus();
}
```

## 2.1.4 Character Key Shortcuts (Level A)

**Requirement**: If a keyboard shortcut is implemented in content using only letter (including upper- and lower-case letters), punctuation, number, or symbol characters, then at least one of the following is true:
- Turn off: A mechanism is available to turn the shortcut off
- Remap: A mechanism is available to remap the shortcut to use one or more non-printable keyboard characters (e.g., Ctrl, Alt)
- Active only on focus: The keyboard shortcut for a user interface component is only active when that component has focus

**Understanding**: Single-key shortcuts can conflict with screen reader commands and assistive technology. Provide alternatives.

**Sufficient Techniques**:
- **G217**: Providing a way to turn off character key shortcuts
- **G218**: Providing a way to remap character key shortcuts

**Example**:
```javascript
// Bad: Single-key shortcut conflicts with screen readers
document.addEventListener('keydown', (e) => {
  if (e.key === 's') {
    saveContent();
  }
});

// Good: Use modifier keys or provide toggle
document.addEventListener('keydown', (e) => {
  if (e.ctrlKey && e.key === 's') {
    e.preventDefault();
    saveContent();
  }
});

// Or provide a toggle
let shortcutsEnabled = true;
document.addEventListener('keydown', (e) => {
  if (!shortcutsEnabled) return;
  if (e.key === 's') {
    saveContent();
  }
});
```
