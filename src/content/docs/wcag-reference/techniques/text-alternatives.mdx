# Text Alternatives Techniques

Providing text alternatives for non-text content ensures all users can access information, regardless of their abilities or technology.

## Image Alt Text

**Technique**: H37 - Using alt attributes on img elements

Provide text alternatives for all informative images.

```html
<!-- Informative image -->
<img src="chart.png" alt="Bar chart showing 50% increase in sales from 2023 to 2024">

<!-- Decorative image -->
<img src="decoration.png" alt="">

<!-- Image with text -->
<img src="logo.png" alt="Company Logo">
```

**Related Criteria**: 1.1.1 Non-text Content

**Best Practices:**
- Be descriptive and concise
- Include relevant information (data, context, purpose)
- Don't repeat information already in surrounding text
- Use empty alt text (`alt=""`) for decorative images
- Avoid "image of" or "picture of" in alt text

## Image Buttons

**Technique**: H36 - Using alt attributes on images used as submit buttons

Provide alt text for images used as buttons.

```html
<input type="image" src="submit.png" alt="Submit Form">
```

**Related Criteria**: 1.1.1 Non-text Content

**Best Practices:**
- Describe the button's action, not its appearance
- Use consistent naming conventions
- Keep alt text concise

## Decorative Images

**Technique**: H67 - Using null alt text and no title attribute on img elements for images that AT should ignore

Use empty alt text for decorative images.

```html
<img src="decoration.png" alt="" role="presentation">
```

**Related Criteria**: 1.1.1 Non-text Content

**Best Practices:**
- Use `alt=""` for purely decorative images
- Add `role="presentation"` for additional clarity
- Don't use `title` attribute on decorative images
- Consider CSS for decorative elements instead

## Complex Images

For complex images like charts, graphs, or diagrams, provide detailed descriptions.

```html
<img src="complex-chart.png" alt="Bar chart showing quarterly sales data for 2024">
<details>
  <summary>Chart Description</summary>
  <p>This bar chart displays quarterly sales data for 2024:</p>
  <ul>
    <li>Q1: $50,000</li>
    <li>Q2: $75,000</li>
    <li>Q3: $60,000</li>
    <li>Q4: $90,000</li>
  </ul>
  <p>Total annual sales: $275,000</p>
</details>
```

**Best Practices:**
- Provide brief alt text for quick understanding
- Include detailed description in expandable section
- Use tables for tabular data when possible
- Consider providing data in alternative formats

## SVG Images

Provide accessible text for SVG graphics.

```html
<svg role="img" aria-labelledby="svg-title">
  <title id="svg-title">Company Logo</title>
  <!-- SVG content -->
</svg>
```

**Best Practices:**
- Use `role="img"` for SVG images
- Provide `<title>` element for description
- Use `aria-labelledby` to reference title
- Include `desc` element for longer descriptions

## Common Mistakes

### 1. Missing Alt Text

```html
<!-- Bad: No alt text -->
<img src="chart.png">

<!-- Good: Descriptive alt text -->
<img src="chart.png" alt="Bar chart showing 50% increase in sales">
```

### 2. Non-Descriptive Alt Text

```html
<!-- Bad: Generic alt text -->
<img src="chart.png" alt="image">

<!-- Good: Descriptive alt text -->
<img src="chart.png" alt="Bar chart showing 50% increase in sales">
```

### 3. Alt Text Too Long

```html
<!-- Bad: Excessively long alt text -->
<img src="chart.png" alt="This is a bar chart that shows the sales data for the year 2024 compared to 2023 with a 50% increase in overall revenue">

<!-- Good: Concise alt text -->
<img src="chart.png" alt="Bar chart showing 50% increase in sales from 2023 to 2024">
```

### 4. Using Decorative Images Without Empty Alt

```html
<!-- Bad: Decorative image without empty alt -->
<img src="decoration.png">

<!-- Good: Empty alt for decorative image -->
<img src="decoration.png" alt="">
```

## Testing Checklist

- [ ] All informative images have descriptive alt text
- [ ] Decorative images have empty alt text
- [ ] Image buttons have descriptive alt text
- [ ] Complex images have detailed descriptions
- [ ] Alt text is concise and informative
- [ ] Alt text doesn't repeat surrounding text
