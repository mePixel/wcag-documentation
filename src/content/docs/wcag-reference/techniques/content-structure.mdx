# Content Structure Techniques

Proper content structure helps users understand and navigate your content effectively.

## Headings

**Technique**: H42 - Using h1-h6 to identify headings

Use proper heading levels to create a logical document structure.

```html
<h1>Main Page Title</h1>

<h2>Section Title</h2>
<p>Section content...</p>

<h3>Subsection Title</h3>
<p>Subsection content...</p>
```

**Related Criteria**: 1.3.1 Info and Relationships, 2.4.6 Headings and Labels

**Best Practices:**
- Use only one `<h1>` per page
- Don't skip heading levels (h1 → h2 → h3)
- Use headings to create outline, not for styling
- Ensure headings are descriptive

## Lists

**Technique**: H48 - Using ol, ul, and dl for lists

Use appropriate list elements for lists of items.

```html
<!-- Unordered list -->
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>

<!-- Ordered list -->
<ol>
  <li>Step 1</li>
  <li>Step 2</li>
  <li>Step 3</li>
</ol>

<!-- Definition list -->
<dl>
  <dt>Term 1</dt>
  <dd>Definition 1</dd>
  <dt>Term 2</dt>
  <dd>Definition 2</dd>
</dl>
```

**Related Criteria**: 1.3.1 Info and Relationships

**Best Practices:**
- Use `<ul>` for unordered lists
- Use `<ol>` for ordered lists
- Use `<dl>` for term-definition pairs
- Don't use lists for layout purposes

## Tables

**Technique**: H51 - Using table markup to present tabular information

Use proper table structure for data tables.

```html
<table>
  <caption>Monthly Sales Data</caption>
  <thead>
    <tr>
      <th scope="col">Month</th>
      <th scope="col">Sales</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">January</th>
      <td>$10,000</td>
    </tr>
    <tr>
      <th scope="row">February</th>
      <td>$12,000</td>
    </tr>
  </tbody>
</table>
```

**Related Criteria**: 1.3.1 Info and Relationships

**Best Practices:**
- Use `<caption>` for table title
- Use `<thead>` and `<tbody>` for structure
- Use `scope` attribute on `<th>` elements
- Avoid using tables for layout
- Provide row and column headers

## Semantic Sections

Use semantic HTML5 sectioning elements.

```html
<section>
  <h2>Section Title</h2>
  <p>Section content...</p>
</section>

<article>
  <h2>Article Title</h2>
  <p>Article content...</p>
</article>

<aside>
  <h2>Related Content</h2>
  <p>Aside content...</p>
</aside>
```

**Best Practices:**
- Use `<section>` for thematic grouping
- Use `<article>` for self-contained content
- Use `<aside>` for tangentially related content
- Include headings in sections for accessibility

## Common Mistakes

### 1. Skipping Heading Levels

```html
<!-- Bad: Skipping levels -->
<h1>Title</h1>
<h3>Subtitle</h3>

<!-- Good: Proper hierarchy -->
<h1>Title</h1>
<h2>Subtitle</h2>
```

### 2. Using Divs for Lists

```html
<!-- Bad: Using divs for lists -->
<div class="list">
  <div class="item">Item 1</div>
  <div class="item">Item 2</div>
</div>

<!-- Good: Using semantic lists -->
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>
```

### 3. Missing Table Headers

```html
<!-- Bad: No table headers -->
<table>
  <tr>
    <td>Month</td>
    <td>Sales</td>
  </tr>
</table>

<!-- Good: With table headers -->
<table>
  <thead>
    <tr>
      <th scope="col">Month</th>
      <th scope="col">Sales</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>January</td>
      <td>$10,000</td>
    </tr>
  </tbody>
</table>
```

## Testing Checklist

- [ ] Headings create logical hierarchy
- [ ] Only one h1 per page
- [ ] No skipped heading levels
- [ ] Lists use appropriate elements
- [ ] Tables have proper headers
- [ ] Tables use caption for title
- [ ] Sections use semantic elements
