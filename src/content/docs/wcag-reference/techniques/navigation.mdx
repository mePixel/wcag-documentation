# Navigation Techniques

Accessible navigation ensures all users can find and move through your content efficiently.

## Skip Links

**Technique**: G1 - Adding a link at the top of each page that goes directly to the main content area

Provide a skip link to bypass repeated navigation.

```html
<body>
  <a href="#main-content" class="skip-link">
    Skip to main content
  </a>
  
  <header>
    <nav>
      <!-- Navigation content -->
    </nav>
  </header>
  
  <main id="main-content">
    <!-- Main content -->
  </main>
</body>

<style>
  .skip-link {
    position: absolute;
    top: -40px;
    left: 0;
    background: #000;
    color: #fff;
    padding: 8px;
    z-index: 100;
  }
  
  .skip-link:focus {
    top: 0;
  }
</style>
```

**Related Criteria**: 2.4.1 Bypass Blocks

**Best Practices:**
- Place skip link as first focusable element
- Use descriptive link text
- Make skip link visible on focus
- Link to main content area with proper ID

## Descriptive Links

**Technique**: G53 - Using the link text to describe the purpose of a link

Use descriptive link text that indicates destination.

```html
<!-- Good: Descriptive link text -->
<a href="/about">Learn about our company</a>
<a href="/article">Read the full article about accessibility</a>

<!-- Bad: Non-descriptive link text -->
<a href="/about">Click here</a>
<a href="/article">Read more</a>
```

**Related Criteria**: 2.4.4 Link Purpose (In Context)

**Best Practices:**
- Use descriptive, unique link text
- Avoid "click here" or "read more"
- Include context when link text is ambiguous
- For icon links, use `aria-label`

## Navigation Landmarks

Use semantic HTML5 navigation elements.

```html
<nav aria-label="Main navigation">
  <ul>
    <li><a href="/">Home</a></li>
    <li><a href="/about">About</a></li>
    <li><a href="/products">Products</a></li>
    <li><a href="/contact">Contact</a></li>
  </ul>
</nav>
```

**Best Practices:**
- Use `<nav>` element for navigation areas
- Provide `aria-label` for multiple navigation areas
- Use ordered or unordered lists for navigation items
- Ensure navigation is keyboard accessible

## Breadcrumb Navigation

Provide breadcrumb trails for orientation.

```html
<nav aria-label="Breadcrumb">
  <ol>
    <li><a href="/">Home</a></li>
    <li><a href="/products">Products</a></li>
    <li aria-current="page">Current Page</li>
  </ol>
</nav>
```

**Best Practices:**
- Use ordered list for breadcrumbs
- Mark current page with `aria-current="page"`
- Provide descriptive labels
- Keep breadcrumbs concise

## Common Mistakes

### 1. Non-Descriptive Link Text

```html
<!-- Bad: Generic link text -->
<a href="/about">Click here</a>
<a href="/products">Read more</a>

<!-- Good: Descriptive link text -->
<a href="/about">Learn about our company</a>
<a href="/products">View our products</a>
```

### 2. Missing Skip Links

```html
<!-- Bad: No skip link -->
<body>
  <header>
    <nav>
      <!-- Long navigation -->
    </nav>
  </header>
  <main>
    <!-- Content -->
  </main>
</body>

<!-- Good: With skip link -->
<body>
  <a href="#main-content" class="skip-link">Skip to main content</a>
  <header>
    <nav>
      <!-- Long navigation -->
    </nav>
  </header>
  <main id="main-content">
    <!-- Content -->
  </main>
</body>
```

### 3. Using Divs for Navigation

```html
<!-- Bad: Non-semantic navigation -->
<div class="navigation">
  <div class="nav-item"><a href="/">Home</a></div>
  <div class="nav-item"><a href="/about">About</a></div>
</div>

<!-- Good: Semantic navigation -->
<nav aria-label="Main navigation">
  <ul>
    <li><a href="/">Home</a></li>
    <li><a href="/about">About</a></li>
  </ul>
</nav>
```

## Testing Checklist

- [ ] Skip links are present and functional
- [ ] All links have descriptive text
- [ ] Navigation uses semantic HTML elements
- [ ] Navigation is keyboard accessible
- [ ] Breadcrumbs indicate current page
- [ ] Multiple navigation methods are available
