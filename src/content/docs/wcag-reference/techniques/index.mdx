# HTML Techniques for WCAG 2.1 AA

This guide covers HTML techniques for meeting WCAG 2.1 Level AA requirements. Using semantic HTML is the foundation of web accessibility and often the most effective way to meet WCAG criteria.

## Overview

HTML provides built-in accessibility features that work with assistive technologies. Using the right HTML elements for the right purpose provides meaning and structure that assistive technologies can understand.

### Key Principles

1. **Use Semantic HTML**: Choose elements based on their meaning, not their appearance
2. **Follow HTML Specification**: Use elements according to their intended purpose
3. **Provide Complete Information**: Ensure all elements have necessary attributes
4. **Maintain Structure**: Use proper nesting and hierarchy

## Best Practices

### 1. Use Semantic HTML

Choose elements based on meaning, not appearance:

```html
<!-- Good: Semantic HTML -->
<button type="button">Submit</button>
<a href="/about">About</a>
<h1>Page Title</h1>

<!-- Bad: Non-semantic HTML -->
<div onclick="submitForm()">Submit</div>
<div onclick="navigate('/about')">About</div>
<div class="title">Page Title</div>
```

### 2. Provide Complete Information

Ensure all elements have necessary attributes:

```html
<!-- Good: Complete attributes -->
<img src="photo.jpg" alt="Sunset over the ocean">
<input type="email" id="email" name="email" required>
<a href="/about" aria-label="Learn about our company">About</a>

<!-- Bad: Missing attributes -->
<img src="photo.jpg">
<input type="email">
<a href="/about">About</a>
```

### 3. Maintain Proper Structure

Ensure proper nesting and hierarchy:

```html
<!-- Good: Proper structure -->
<header>
  <nav>
    <ul>
      <li><a href="/">Home</a></li>
      <li><a href="/about">About</a></li>
    </ul>
  </nav>
</header>

<main>
  <h1>Page Title</h1>
  <h2>Section Title</h2>
  <p>Content...</p>
</main>

<!-- Bad: Improper structure -->
<div>
  <nav>
    <div>
      <a href="/">Home</a>
    </div>
  </nav>
</div>
```

### 4. Test with Assistive Technologies

Verify your HTML works with assistive technologies:

- Screen readers (NVDA, JAWS, VoiceOver, TalkBack)
- Screen magnifiers
- Voice recognition software

## Common Mistakes

### 1. Using Divs Instead of Semantic Elements

```html
<!-- Bad: Using divs -->
<div class="button" onclick="submitForm()">Submit</div>

<!-- Good: Using button element -->
<button type="button">Submit</button>
```

### 2. Missing Alt Text

```html
<!-- Bad: No alt text -->
<img src="chart.png">

<!-- Good: Descriptive alt text -->
<img src="chart.png" alt="Bar chart showing 50% increase in sales">
```

### 3. Using Placeholder Text as Labels

```html
<!-- Bad: Placeholder as label -->
<input type="email" placeholder="Email Address">

<!-- Good: Proper label -->
<label for="email">Email Address</label>
<input type="email" id="email">
```

### 4. Skipping Heading Levels

```html
<!-- Bad: Skipping levels -->
<h1>Title</h1>
<h3>Subtitle</h3>

<!-- Good: Proper hierarchy -->
<h1>Title</h1>
<h2>Subtitle</h2>
```
