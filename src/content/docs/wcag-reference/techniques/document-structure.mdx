# Document Structure Techniques

Proper document structure provides the foundation for accessible web pages. These techniques ensure assistive technologies can understand and navigate your content.

## Language Declaration

**Technique**: H57 - Using language attributes on html element

Set the default language of your page to help screen readers use the correct pronunciation.

```html
<html lang="en">
  <head>
    <title>English Page</title>
  </head>
  <body>
    <p>This page is in English.</p>
  </body>
</html>
```

**Related Criteria**: 3.1.1 Language of Page

**Best Practices:**
- Always specify the language on the `<html>` element
- Use the correct language code (e.g., "en" for English, "es" for Spanish)
- For multilingual content, use the `lang` attribute on specific elements

## Page Title

**Technique**: H25 - Providing a title using the title element

Provide a unique, descriptive title for each page.

```html
<head>
  <title>About Us - Company Name</title>
</head>
```

**Related Criteria**: 2.4.2 Page Titled

**Best Practices:**
- Make titles unique for each page
- Include the most important information first
- Keep titles concise but descriptive
- Format: "Page Name - Site Name"

## Document Type Declaration

**Technique**: H91 - Using HTML form controls and links

Always include a proper DOCTYPE declaration.

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>Page Title</title>
  </head>
  <body>
    <!-- Page content -->
  </body>
</html>
```

**Best Practices:**
- Use `<!DOCTYPE html>` for HTML5 documents
- Place DOCTYPE at the very beginning of the document
- Don't use older DOCTYPE declarations unless necessary

## Meta Tags

Provide essential metadata about your document.

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Page description for search engines">
  <meta name="author" content="Author Name">
</head>
```

**Best Practices:**
- Always specify character encoding (UTF-8 recommended)
- Include viewport meta tag for responsive design
- Provide description meta tag for SEO
- Include author and other relevant metadata

## Common Mistakes

### 1. Missing Language Declaration

```html
<!-- Bad: No language specified -->
<html>
  <head>
    <title>Page Title</title>
  </head>
</html>

<!-- Good: Language specified -->
<html lang="en">
  <head>
    <title>Page Title</title>
  </head>
</html>
```

### 2. Non-Descriptive Page Titles

```html
<!-- Bad: Generic title -->
<title>Home</title>

<!-- Good: Descriptive title -->
<title>Home - Company Name</title>
```

### 3. Missing DOCTYPE

```html
<!-- Bad: No DOCTYPE -->
<html>
  <head>
    <title>Page Title</title>
  </head>
</html>

<!-- Good: With DOCTYPE -->
<!DOCTYPE html>
<html>
  <head>
    <title>Page Title</title>
  </head>
</html>
```
