Text resizing allows users to adjust text size to meet their needs. Flexible text sizing is essential for accessibility.

## Overview

WCAG 2.1 Level AA requires that text can be resized up to 200% without loss of content or functionality.

### Why Text Resizing Matters

- **Low Vision Users**: Need larger text to read comfortably
- **Elderly Users**: Benefit from larger text sizes
- **Cognitive Users**: May need larger text for better comprehension
- **All Users**: Benefit from flexible text sizing

## WCAG Requirements

### 1.4.4 Resize Text (Level AA)

Except for captions and images of text, text can be resized without assistive technology up to 200 percent without loss of content or functionality.

### 1.4.10 Reflow (Level AA)

Content can be presented without loss of information or functionality, and without requiring two-dimensional scrolling.

## Quick Start

### Basic Implementation

```css
/* Set root font size */
html {
  font-size: 100%;
}

/* Use relative units */
body {
  font-size: 1rem;
}

h1 {
  font-size: 2.5rem;
}

h2 {
  font-size: 2rem;
}
```

### Fluid Typography

```css
/* Use clamp() for responsive headings */
h1 {
  font-size: clamp(2rem, 5vw, 3rem);
}

h2 {
  font-size: clamp(1.5rem, 4vw, 2.5rem);
}
```

### Responsive Scaling

```css
/* Use media queries for breakpoints */
html {
  font-size: 100%;
}

@media (min-width: 768px) {
  html {
    font-size: 110%;
  }
}

@media (min-width: 1024px) {
  html {
    font-size: 120%;
  }
}
```

## Key Principles

### 1. Use Relative Units

Always use relative units (rem, em, percentage) for text sizing to ensure text scales with user preferences.

### 2. Test Text Resizing

Verify content works at 200% text size:
- Set browser zoom to 200%
- Verify all text is readable
- Verify no horizontal scrolling
- Verify all functionality works

### 3. Ensure Flexible Layouts

Layouts should accommodate text resizing:
- Use max-width instead of fixed width
- Use overflow: auto for containers
- Ensure content doesn't overflow
- Test at different text sizes

### 4. Respect User Preferences

Honor user's text size preferences:
- Use 100% as root font size
- Respect browser zoom settings
- Use prefers-reduced-motion media query
- Use prefers-contrast media query
