Color contrast ensures text and graphical objects are readable for users with visual impairments, including color blindness and low vision.

## Overview

WCAG 2.2 Level AAA requires specific contrast ratios between text and its background. These requirements ensure content is readable for users with various visual abilities.

### Why Color Contrast Matters

- **Low Vision Users**: Need sufficient contrast to read text
- **Color Blind Users**: Can't rely on color differences alone
- **All Users**: Benefit from clear, readable content
- **Aging Users**: Experience reduced contrast sensitivity

## WCAG Requirements

### 1.4.6 Contrast (Enhanced) (Level AAA)

Text and images of text must have a contrast ratio of at least 7:1, except for:

- **Large Text**: Contrast ratio of at least 4.5:1
- **Incidental**: Text or images of text that are part of an inactive user interface component, pure decoration, or not visible to anyone
- **Logotypes**: Text that is part of a logo or brand name

> **Note:** SC 1.4.3 Contrast (Minimum) (Level AA) establishes baseline requirements of 4.5:1 for normal text and 3:1 for large text. SC 1.4.6 raises these thresholds to 7:1 and 4.5:1 respectively for enhanced readability.

### 1.4.11 Non-text Contrast (Level AA)

The visual presentation of user interface components and graphical objects must have a contrast ratio of at least 3:1 against adjacent colors.

## Contrast Ratios

### Text Contrast Requirements

| Text Type | Minimum Contrast | WCAG Level |
|-----------|------------------|-------------|
| Normal text (under 18pt or 14pt bold) | 7:1 | AAA |
| Large text (18pt and up, or 14pt bold and up) | 4.5:1 | AAA |
| Graphical objects | 3:1 | AA |
| UI components | 3:1 | AA |

### Text Size Definitions

- **Normal text**: Under 18 point (24px) or under 14 point bold (18.67px bold)
- **Large text**: 18 point (24px) and up, or 14 point bold (18.67px bold) and up

## Calculating Contrast

### Contrast Ratio Formula

Contrast ratio is calculated using the following formula:

```
(L1 + 0.05) / (L2 + 0.05)

Where:
- L1 = relative luminance of the lighter color
- L2 = relative luminance of the darker color
```

### Luminance Formula

```
L = 0.2126 * R + 0.7152 * G + 0.0722 * B

Where R, G, and B are:
- If RsRGB <= 0.03928: RsRGB / 12.92
- Else: ((RsRGB + 0.055) / 1.055) ^ 2.4
```

## Implementation Examples

### Good Contrast Examples

```css
/* Good: High contrast (7:1 or higher for AAA) */
body {
  color: #333333;
  background-color: #ffffff;
}

/* Good: Large text with contrast (4.5:1 or higher for AAA) */
h1 {
  color: #444444;
  font-size: 24px;
}

/* Good: UI components with sufficient contrast (3:1 or higher) */
button {
  color: #ffffff;
  background-color: #005fcc;
}

/* Good: Links with sufficient contrast */
a {
  color: #005fcc;
  text-decoration: underline;
}
```

### Bad Contrast Examples

```css
/* Bad: Low contrast (below 7:1 for AAA) */
body {
  color: #999999;
  background-color: #ffffff;
}

/* Bad: Links with insufficient contrast */
a {
  color: #cccccc;
  text-decoration: none;
}

/* Bad: Buttons with insufficient contrast */
button {
  color: #ffffff;
  background-color: #cccccc;
}
```

## Common Mistakes

### 1. Using Light Gray on White

```css
/* Bad: Low contrast */
body {
  color: #cccccc;
  background-color: #ffffff;
}

/* Good: Sufficient contrast */
body {
  color: #333333;
  background-color: #ffffff;
}
```

### 2. Using Color Alone to Convey Information

```css
/* Bad: Color alone */
.error {
  color: red;
}

/* Good: Color + text + icon */
.error {
  color: #d32f2f;
  font-weight: bold;
}
.error::before {
  content: "⚠ ";
}
```

### 3. Not Checking Contrast on All States

```css
/* Bad: Only checking default state */
button {
  color: #ffffff;
  background-color: #005fcc;
}

/* Good: Checking all states */
button {
  color: #ffffff;
  background-color: #005fcc;
}

button:hover {
  background-color: #0047b3;
}

button:focus {
  outline: 3px solid #005fcc;
  outline-offset: 2px;
}

button:disabled {
  color: #999999;
  background-color: #f5f5f5;
}
```

### 4. Misapplying Large Text Contrast for AAA

Under SC 1.4.6 (Level AAA), the large text exception is narrower than under AA. Large text still requires 4.5:1, not 3:1.

```css
/* Bad: Using 3:1 for large text — insufficient for AAA */
h1 {
  color: #666666;
  font-size: 24px;
}

/* Good: Using 4.5:1 for large text (18pt+) — meets SC 1.4.6 */
h1 {
  color: #444444;
  font-size: 24px;
}

/* Good: Using 7:1 for normal text — meets SC 1.4.6 */
p {
  color: #333333;
  background-color: #ffffff;
}
```

## Best Practices

### 1. Use Sufficient Contrast

Ensure all text meets minimum contrast requirements.

```css
/* Good: Sufficient contrast */
body {
  color: #333333;
  background-color: #ffffff;
}

h1 {
  color: #444444;
  font-size: 24px;
}
```

### 2. Test All States

Check contrast on hover, focus, active, and disabled states.

```css
button {
  color: #ffffff;
  background-color: #005fcc;
}

button:hover {
  background-color: #0047b3;
}

button:focus {
  outline: 3px solid #005fcc;
  outline-offset: 2px;
}

button:disabled {
  color: #999999;
  background-color: #f5f5f5;
}
```

### 3. Use Multiple Indicators

Don't rely on color alone to convey information.

```css
/* Good: Color + text + icon */
.error {
  color: #d32f2f;
  font-weight: bold;
}
.error::before {
  content: "⚠ ";
}

.success {
  color: #388e3c;
  font-weight: bold;
}
.success::before {
  content: "✓ ";
}
```

### 4. Test with Tools

Use contrast checkers to verify compliance.

- Test all text and background combinations
- Test all interactive states
- Test with different color blindness simulators

## SC 1.4.8 Visual Presentation (Level AAA)

SC 1.4.8 complements the contrast requirements by specifying additional typographic and layout properties that improve readability for users with low vision and cognitive disabilities.

### Requirements

- **Line height**: At least 1.5 times the font size for blocks of text
- **Paragraph spacing**: At least 2em between paragraphs
- **Line length**: No more than 80 characters per line
- **Text alignment**: Text is not justified (aligned to both left and right margins)

### CSS Example

```css
.readable-text {
  line-height: 1.5;
  margin-bottom: 2em;
  max-width: 80ch; /* Limits line length to ~80 characters */
  text-align: left; /* Avoid justified alignment */
}

.readable-text p + p {
  margin-top: 2em; /* Paragraph spacing of at least 2em */
}
```

> **Note:** These properties can be provided through user agent stylesheets, bookmarklets, or built-in page styles. They do not need to be the default, but must be achievable without requiring users to create custom stylesheets.
