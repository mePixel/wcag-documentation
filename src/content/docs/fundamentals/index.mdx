## Why Accessibility Matters

Web accessibility ensures that people with disabilities can perceive, understand, navigate, and interact with websites and tools. It also benefits others, including:

- Older people with changing abilities
- People with temporary disabilities (like a broken arm)
- People with situational limitations (like bright sunlight or noisy environments)
- People using mobile devices or slow internet connections

## The POUR Principles

WCAG is organized around four principles that provide the foundation for web accessibility:

1. **Perceivable**: Information and user interface components must be presentable to users in ways they can perceive
2. **Operable**: User interface components and navigation must be operable
3. **Understandable**: Information and the operation of user interface must be understandable
4. **Robust**: Content must be robust enough that it can be interpreted reliably by a wide variety of user agents, including assistive technologies

## WCAG Compliance Levels

WCAG has three levels of conformance:

- **Level A**: The most basic web accessibility features
- **Level AA**: Deals with the biggest and most common accessibility barriers
- **Level AAA**: The highest and most complex level of web accessibility

## What's New in WCAG 2.2

WCAG 2.2 introduces several important new success criteria over WCAG 2.1:

- **Focus Not Obscured (2.4.11)** and **Focus Appearance (2.4.12)** — Ensure focus indicators are always visible and meet enhanced appearance requirements
- **Dragging Movements (2.5.7)** — Provide alternatives to drag-and-drop interactions
- **Target Size (2.5.8)** — Minimum 24×24px (AA) or 44×44px (AAA) for interactive elements
- **Consistent Help (3.2.6)** — Help mechanisms in a consistent location across pages
- **Redundant Entry (3.3.7)** — Auto-populate previously entered data to avoid re-entry
- **Accessible Authentication (3.3.8)** — No cognitive function tests for authentication
- **Timeouts (2.2.6)** — 20-second warning before session timeouts
- **Removed**: SC 4.1.1 Parsing was removed, as modern browsers and assistive technologies no longer require it
